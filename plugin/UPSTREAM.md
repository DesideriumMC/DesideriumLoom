# Upstream origin

DesideriumLoom is derived from [Voldeloom](https://github.com/CrackedPolishedBlackstoneBricksMC/voldeloom), branch `disaster-time`, commit `da68a85cc6b5b6e336edd6f37db37f5b9657441e`.

Changes include Forge sided-member handling, the `dev.desiderium.loom` plugin and `desiderium` DSL, Mixin annotation processing and mapping support, release remapping, Java 8 Loader support, source generation and IDE integration.

Original MIT notices remain in LICENSE and source headers. Bundled LZMA and Stitch notices are retained under src/main/resources. Upstream and dependency licenses continue to apply.
